## Experiment and archival integrity

runs, ten bonus-off runs, ten NoSafety runs and six exploratory transfer phases.
All reported suites are regenerated by the shell reproducer, not copied from
historical artifacts. Seven top-level artifact comparisons include all metrics,
per-run/person values, narrative samples, metadata and source fingerprints.
Numeric comparison uses rtol=1e-10 and atol=1e-12; no timing or outcome field is
stripped. A separate comparator check accepts a 1e-13 float perturbation and
rejects a material 0.1 reward change.

SVR values 0. Narrative rendering totals 168,000 with zero recorded fallback.
Each run asserts zero skipped physical outcomes, correct completion counts and
one SAPS Beta observation per actual attempt. NoSafety violations are retained,
not removed to obtain a clean table.

The 35 original result files were moved byte-for-byte into archive/pre-submission;
all SHA256 values match the pre-change manifest. Numerical input JSON is unchanged.
CLI, live agent and reproducer do not alter final reference JSON. Credential-pattern
and configured-key scans found no credential in the delivered source/evidence.
