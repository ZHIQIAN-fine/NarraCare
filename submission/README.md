The source archive extracts into `narracare_final/`. Its `SUBMISSION_MANIFEST.json`
records the exact source commit and hashes of included files. It excludes Git
metadata, credentials, virtual environments, caches, old versions and delivery
bundles. Current configurations, inputs, final results, tests and demo are included.

The Word uses A4, Arial 11pt, single spacing and the required margins. Its cloud
layout proof has 11 pages using substitute fonts. **Export the formal PDF locally
with Arial and verify 8–12 pages including references.** No substitute-font cloud
PDF is supplied as the formal submission. Repository privacy, teaching-team
access and NTULearn PDF upload remain the owner's actions.

Follow [the root README](../README.md) after extracting. The live chat demo
requires an OpenAI-compatible provider key and network; the integrated benchmark
CLI and reproduction are offline after dependency installation. A fresh learner
is used per live session; no pretrained patient data is needed.
